Nha Guinendade

Site de apresentação da marca e dos seus 19 produtos, em português europeu. Inclui filtros, pesquisa sem distinção de acentos e fichas individuais. Não inclui carrinho, seleção para encomendas, pagamentos ou chamadas de venda. Os contactos são apenas informativos.

Esta pasta é independente do projeto Frutas e Legumes na raiz do repositório. O projeto Vercel frutas_e_legumes-nha-guinendade usa nha-guinendade como Root Directory.

Para editar os produtos, alterar products.mjs. Para editar a página, alterar src/index.html. Executar npm run build nesta pasta para atualizar index.html. Não editar o index.html gerado diretamente. O build usa apenas Node.js e não necessita de dependências.

Executar npm test após o build. Para verificar localmente, usar python -m http.server 4173 nesta pasta e abrir http://localhost:4173. A aplicação necessita de HTTP para carregar módulos JavaScript.

styles.css contém a apresentação e app.js contém os filtros e os diálogos informativos. A pasta assets contém o logótipo aprovado, fotografias e ilustrações WebP. FONTES.txt documenta a origem dos conteúdos e as limitações editoriais.

Build Command npm run build && npm test && node --check app.js. Output Directory dist. O build copia apenas os ficheiros públicos necessários para dist. Não são necessárias variáveis de ambiente.
