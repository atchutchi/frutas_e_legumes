# Nha Guinendade — Website institucional

Site institucional responsivo, em português, da Nha Guinendade — marca guineense de produtos agroalimentares locais, fundada por Maria de Fátima Silva Lopes, em Pelundo, Região de Cacheu, Guiné-Bissau.

## Publicar no Vercel

1. Abra https://vercel.com/new e importe o repositório `atchutchi/frutas_e_legumes`.
2. Nas configurações de importação escolha **Root Directory: `nha-guinendade`**. O código desta pasta é independente do projeto Frutas e Legumes.
3. Framework Preset: **Other**; Build Command: deixe em branco; Output Directory: deixe em branco.
4. Clique **Deploy**.
5. Desative qualquer proteção/autenticação do deployment de produção e teste numa janela anónima.
6. Só depois de confirmar o endereço público de produção é que deve criar/imprimir o QR Code.

## Ficheiros
- `index.html`: página completa com HTML, CSS e JS.
- `assets/`: logótipo, imagens da fundadora, produtos e fundo.
- `vercel.json`: configurações do site estático.
